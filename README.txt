APLIKASI PENDAFTARAN SISWA BARU (PPDB)

Teknologi:
- HTML
- CSS
- JavaScript
- LocalStorage (penyimpanan di browser)

CARA MEMBUKA DI VISUAL STUDIO CODE:
1. Ekstrak file ZIP.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder.
4. Pilih folder Aplikasi_Pendaftaran_Siswa_Baru.
5. Buka file index.html.
6. Klik kanan pada index.html lalu pilih Open with Live Server.
   Bisa juga klik dua kali index.html untuk membuka langsung di browser.

FITUR:
1. Form identitas calon siswa.
2. Input NISN dengan validasi 10 digit.
3. Input tanggal lahir dan alamat.
4. Pilihan jurusan.
5. Data orang tua/wali dan nomor HP.
6. Validasi formulir wajib isi.
7. Halaman konfirmasi sebelum mendaftar.
8. Nomor pendaftaran otomatis.
9. Data pendaftaran disimpan di LocalStorage browser.
10. Bukti pendaftaran dapat dicetak.

CATATAN:
Aplikasi ini adalah contoh proyek front-end untuk praktik HTML, CSS, dan JavaScript.
Data disimpan di browser yang digunakan dan belum terhubung ke database/server sekolah.
